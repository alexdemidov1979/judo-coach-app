## 3. Список всех внесённых изменений

### Интерфейс
- Единый радиус карточек, тактильный отклик (нажатие/отпускание) на кнопках, плитках, карточках
- Плавные переходы между вкладками
- Цветовая схема оставлена без изменений (по вашей просьбе)

### Видео
- Все ссылки на техники переведены с Google Drive на реальные видео вашего канала RuTube (94 ссылки сопоставлены автоматически по названию техники)
- Исправлена причина, по которой видео не открывались на телефоне (Google Drive `uc?export=download` не работал как поток; заменено на официальный `/preview`-эмбед — актуально для оставшихся Drive-ссылок, если появятся)

### Библиотека / Техника
- Объединены в один раздел: Аттестация по кю, 100 техник Кодокан, Терминология, Судейские правила МФД, Разминка/игры/СФП/заминка
- Убрана дублирующая вкладка «Терминология»

### Карточка техники
- Полные карточки для всех **87 техник Кодокан**: пояс, описание, этапы выполнения, типичные ошибки, комбинации, контрприёмы/защита, похожие техники (кликабельны), заметки тренера (сохраняются)

### Судейские правила
- Загружен и структурирован официальный документ «Судейские правила МФД» (ред. 24.07.2026): жесты, статьи 1–21, с поиском

### Поиск
- Единый глобальный поиск (кнопка 🔍) сразу по техникам, терминам, правилам, программе по кю, разминке/играм, ученикам, заметке дня

### Ученики
- Фото (с автообрезкой в круг), рост, дата получения пояса
- Любимые техники, слабые стороны, травмы, индивидуальные задания, достижения
- Автоматическая история изменений (пояс, вес, травмы, справки, оплата — с датами)

### Посещаемость
- 3 состояния вместо одного: был / по уважительной причине / отсутствовал (тап по чипу)
- Автоматический % посещаемости на карточке ученика (уважительные причины не портят процент)

### Оплаты
- Тип абонемента, дата окончания (с напоминанием за 7 дней)
- Кнопка «Записать оплату сегодня» + история оплат
- Автоподсчёт долга по явно неоплаченным месяцам

### Экзамены
- Отдельный раздел: «Готовы к экзамену» / «В процессе подготовки» с прогресс-баром и указанием следующего пояса
- Бейдж 🎓 в карточке и списке учеников при 100% готовности

### Соревнования
- Календарь соревнований, участники (из списка учеников), места 1/2/3/участие
- Медали автоматически пишутся в «Достижения» ученика
- Карточка «Ближайшее соревнование» на главном экране

### Конструктор тренировок
- 9 типов блоков (разминка, акробатика, ОФП, СФП, техника, партер, рандори, игры, заминка)
- Drag & Drop для изменения порядка, сохранение/загрузка шаблонов
- Вставка готовой структуры в план на сегодня одной кнопкой

### Таймеры
- Вибрация на старт/раунд/финиш во всех таймерах
- Пресеты для Табата (сохранение/загрузка/удаление своих настроек)

### AI-помощник
- Интеграция с DeepSeek API (свой ключ, хранится только на устройстве)
- 4 быстрых действия + свободный чат + контекстная кнопка «Проанализировать» в карточке ученика
- Обезличивание имён перед отправкой (переключатель, по умолчанию включён)

### Аналитика
- 5 графиков (Chart.js): тренировки и часы, посещаемость, пояса, освоенные техники по группам, медали

### Производительность
- XLSX и Chart.js больше не блокируют загрузку — подгружаются только при реальном использовании
- Кэш расчёта посещаемости (8 сек) вместо пересканирования всей истории при каждом открытии

### PWA
- `sw.js`: баннер автообновления вместо тихой подмены версии, офлайн-фолбэк на `index.html`
- `manifest.json`: ярлыки быстрого доступа (Сегодня/Ученики/Таймеры)
- Локальные напоминания (справки, соревнования) — работают только пока приложение открыто

### Доступность
- Видимый фокус при навигации с клавиатуры, skip-link, Escape закрывает модалки
- ARIA-роли и метки, aria-live для чата AI и результатов поиска, alt-тексты фото
- Поддержка `prefers-reduced-motion`

### Резервное копирование
- Добавлен `schemaVersion`, в дамп включены соревнования и шаблоны конструктора (раньше терялись)

## 4. Исправленные ошибки

- Видео не воспроизводились на телефоне (Google Drive `uc?export=download`)
- Опечатка/пропуск строки объявления функции при трёх правках (найдено и исправлено сразу же)
- Дублирование `id="global-search-results"` между старым и новым поиском
- Несовпадение написания romaji между кодом и данными (`Harai-tsurikomi-ashi`, `Kata-te-jime`, `Ryo-te-jime` и др.)

## 5. Известные ограничения

- AI работает только с вашим личным API-ключом DeepSeek (статический сайт без backend не может безопасно хранить общий ключ)
- Push-уведомления с закрытым приложением невозможны без отдельного backend-сервера — реализованы только локальные напоминания
- Полный аудит цветового контраста не проводился (требует визуальной проверки в браузере)
- Весовые категории участников соревнований — поле не добавлено (только возрастная категория)

- Экспорт годового плана в PDF/Word одной кнопкой
- Учёт весовых категорий участников соревнований
- AI-планирование на неделю вперёд с учётом истории прошлых тренировок (сейчас каждый запрос независим)
